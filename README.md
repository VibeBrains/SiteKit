# SiteKit

Общий каркас лендингов семейства Vibe: [vibememory.ru](https://vibememory.ru), [vibeide.ru](https://vibeide.ru), [vibeidea.ru](https://vibeidea.ru).
Сайты разные по характеру, а каркас у них один: правила текстов, языки, базовые стили, шапка и подвал, релизы, выкладка.
Раньше каркас жил тремя копиями и начинал расходиться — теперь у него один источник.

## Что в пакете

- `languages` — русский базовый по адресу `/`, английский по `/en/`, теги языков
- `i18n` — `createI18n(каталоги)`: переводчик с откатом на русскую строку и именованными подстановками `{name}`; каталоги и тип ключей остаются в сайте
- `gate` — `localeGate({ root, catalogs, data })`: гейт локализации для `bun test` — одинаковые ключи и подстановки, одна мысль на строку, каждый ключ используется, в разметке и собранных страницах нет текста мимо каталога
- `styles/base.css` — сброс, сетка, кнопки, шапки секций, плотная строка героя, появление при прокрутке; всё в слое `@layer kit` и на переменных сайта
- `components/Base.astro` — оболочка страницы: мета, ранний выбор языка, ссылка «к содержимому»
- `components/Header.astro`, `Footer.astro` — шапка и подвал; знак продукта — в слот `logo`
- `components/Lines.astro` — строка каталога по предложению на строку
- `components/FusedLine.astro` — плотная строка героя с вывернутыми буквами
- `components/DownloadButtons.astro` — кнопки скачивания по платформам
- `components/Family.astro` — секция семейства с настоящими иконками продуктов
- `brands` — названия продуктов семейства и их иконки
- `releases` — разбор релизов GitHub: последняя сборка каждой платформы, загрузка при сборке
- `scripts/reveal`, `scripts/motion`, `scripts/langMemory`, `scripts/tilt`, `scripts/liveReleases` — клиентские скрипты
- `site-deploy` — выкладка сборки на общий хост: `site-deploy --site /srv/<продукт>/site`

## Что остаётся в сайте

Личность: секции, сцены, тексты, палитра, шрифты, знак.
Тема сайта задаёт переменные, которые читает `base.css`, — список в шапке `src/styles/base.css`.
Тема не в слое, поэтому перекрывает каркас без борьбы за специфичность.

## Подключение

```json
"dependencies": {
  "@vibebrains/site-kit": "github:VibeBrains/SiteKit#v0.1.0"
}
```

Пакет отдаёт исходники `.ts` и `.astro`: их компилирует сборка сайта, отдельной сборки у пакета нет.
Версия закреплена тегом: сайт не меняется, пока его не обновили.
Обновление — новый тег здесь и новый тег в `package.json` сайта, затем `bun install`.

## Правила

Комментарии в коде — по-английски, тексты для людей приходят из каталога сайта.
Ни одной строки интерфейса в пакете: всё, что видит человек, сайт передаёт свойствами.
Изменение каркаса проверяется на всех трёх сайтах: сборка, `astro check`, гейт и сравнение собранных страниц.

## Грабли

- **Токены не кладутся в слой `kit`.** Переменная на `:root` из слоя проигрывает любой переменной на `:root` вне слоя, даже внутри `@media`.
  Поэтому мобильные значения токенов (`--gutter`, `--section-y`) живут в теме сайта, а не здесь, — иначе на телефоне остался бы десктопный отступ.
- **Слот получает стили родителя, а не компонента.** Знак в слоте `logo` шапки стилизует сайт; правила для кнопок шапки пакет задаёт сам, через свойства `actions`.
- **Проверка переноса — по вычисленным стилям, не только по тексту.** Сравнение собранных страниц ловит тексты и разметку, а сдвиг каскада видно только в `getComputedStyle` каждого элемента: так нашлась забытая переменная карточки семейства.
